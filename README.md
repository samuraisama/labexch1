# A little corner of the internet

A one-page romantic note with the photos and video supplied for the project. The song player embeds **Dilerim Ki** by Dolu Kadehi Ters Tut through Spotify.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open **Actions → Deploy romantic page to GitHub Pages** and rerun the failed run (or run the workflow manually).

The site URL will be:

https://samuraisama.github.io/labexch1/

The site is a public page and includes embedded copies of the supplied photos and video. Anyone with the URL can view and save them, so publish/share it only with the subject's consent.
